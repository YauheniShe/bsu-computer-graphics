# Компьютерная графика

Лабораторные работы по курсу «Компьютерная графика» в БГУ.

## Лабораторные работы

Номер в группе: **13**. Для заданий с разделением по чётности используются нечётные варианты.

| № | Тема | Реализация |
|---|---|---|
| [01](labs/lab01/) | Цветовые модели: CMYK, RGB, HLS | Python + Tkinter, без сторонних библиотек |

## Запуск первой лабораторной

```bash
cd labs/lab01
python3 app.py
```

Нужен Python 3.10+ с Tkinter. На Windows можно использовать `py app.py`.
На macOS также можно открыть `labs/lab01/run.command` двойным щелчком.

Условие, инструкции, формулы и команды проверки находятся в [папке работы](labs/lab01/).
