# Компьютерная графика

Лабораторные работы по курсу «Компьютерная графика» в БГУ.

## Лабораторные работы

Работы будут размещаться в папке [`labs/`](labs/), каждая — в отдельной подпапке `lab01`, `lab02` и т. д.

Для каждой работы в её `README.md` указываются:

- тема и условие задания;
- необходимые зависимости и команды запуска;
- примеры результатов, если они нужны для проверки.

Лабораторные работы пока не добавлены.
