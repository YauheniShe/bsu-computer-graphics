## Запуск

Открой папку `labs/lab01` и дважды щёлкни:

- **macOS:** `Запустить лабораторную.command`;
- **Windows:** `Запустить лабораторную.bat`.

Нужен Python 3.10+ с Tkinter. Дополнительных библиотек нет.

Из терминала:

```bash
python3 labs/lab01/app.py
```
