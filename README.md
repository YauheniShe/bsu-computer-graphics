# Компьютерная графика

Лабораторные работы БГУ. Номер в группе — 13.

| Работа | Тема |
|---|---|
| [1](labs/lab01/) | Цветовые модели CMYK, RGB, HLS |
| [2](labs/lab02/) | Локальные пороги и повышение резкости |

## Запуск

Открой папку нужной работы (`labs/lab01` или `labs/lab02`) и дважды щёлкни:

- **macOS:** `Запустить лабораторную.command`;
- **Windows:** `Запустить лабораторную.bat`.

Нужен Python 3.10+ с Tkinter. Вторая работа при первом запуске устанавливает NumPy и Pillow в отдельное окружение.

Условие, инструкции и пояснения находятся в папке каждой работы.
