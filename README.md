## Запуск

Открой папку нужной работы в `labs/` и дважды щёлкни:

- **macOS:** для работ 3 и 4 — `run.command`, для работ 1 и 2 — `Запустить лабораторную.command`;
- **Windows:** для работ 3 и 4 — `run.bat`, для работ 1 и 2 — `Запустить лабораторную.bat`.

Нужен Python 3.10+ с Tkinter. Вторая работа при первом запуске устанавливает NumPy и Pillow в отдельное окружение.

Условие, инструкции, пояснения и отчёт PDF с исходником LaTeX находятся в папке каждой работы.
