# Алгоритмы отсечения

## Сазерленд — Коэн

Прямоугольник задаётся границами `xmin ymin xmax ymax`. Код конца отрезка состоит из четырёх битов.

| Бит | Положение |
|---|---|
| `0001` | `x < xmin` |
| `0010` | `x > xmax` |
| `0100` | `y < ymin` |
| `1000` | `y > ymax` |

На самой границе соответствующий бит равен нулю. Если побитовое ИЛИ кодов равно нулю, оба конца внутри и отрезок принимается. Если побитовое И кодов отлично от нуля, существует граница, за которой лежат оба конца, и отрезок отбрасывается.

В остальных случаях выбираем внешний конец и пересекаем содержащую отрезок прямую с одной из указанных кодом границ. Уравнение прямой `y = y0 + k·(x−x0)`, где `k = (y1−y0)/(x1−x0)`. На вертикальной границе подставляем `x` и находим `y`. На горизонтальной границе используем `x = x0 + (y−y0)/k`. Для вертикальной прямой `x = x0`, а горизонтальный отрезок проверяется по `Y` на этапе сравнения кодов. После пересечения заменяем внешний конец и снова вычисляем коды.

В [примере](samples/segments.txt) прямая первого отрезка имеет вид `y = 1 + x/2`. Для первого конца получаем точки `(−8,−3)` и `(−6,−2)`, для второго — `(8,5)` и `(6,4)`. Остаётся отрезок `(−6,−2) → (6,4)`. Касание в одной точке тоже считается видимым.

## Сазерленд — Ходжман

Вершины каждого выпуклого контура идут по порядку обхода. Для ребра окна `A → B` считаем ориентированную величину

```text
d(P) = σ·((Bx−Ax)·(Py−Ay) − (By−Ay)·(Px−Ax))
```

Знак `σ` равен `+1` при обходе окна против часовой стрелки и `−1` при обходе по часовой. Полуплоскость `d(P) ≥ 0` содержит окно. Для каждого ребра текущего контура `P → Q`:

| `P` | `Q` | Что добавить |
|---|---|---|
| Внутри | Внутри | `Q` |
| Внутри | Снаружи | Пересечение |
| Снаружи | Внутри | Пересечение, `Q` |
| Снаружи | Снаружи | — |

При переходе через границу `t = d(P)/(d(P)−d(Q))`, `I = P + t·(Q−P)`. Выход очередного прохода используется для следующего ребра окна. Совпадающие соседние точки объединяются. При касании может остаться одна точка или отрезок.

В [примере с прямоугольным окном](samples/polygon.txt) после четырёх проходов получается 5, 5, 6 и 6 вершин. Видимый контур имеет вершины `(−4,2), (−4,−3), (5,−3), (5,1), (2,4), (−2,4)` и площадь `56.5`.

## Координаты и вычисления

Вычисления с координатами идут в рациональных числах `Fraction`. Попадание на границу и совпадение вершин проверяются точно. Для вывода на Canvas используется преобразование `X = ox + s·x`, `Y = oy − s·y`. Масштаб `s` одинаков вдоль обеих осей. При изменении масштаба меняется шаг линий сетки, координаты фигур остаются прежними.
