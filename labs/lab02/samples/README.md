# Тестовые изображения

Изображения созданы `make_samples.py`, размер — 720 × 480. Генератор случайных чисел NumPy использует seed 13. Для текста взят встроенный шрифт Pillow. Набор в репозитории создан с NumPy 2.5.4 и Pillow 12.3.0.

| Файл | Содержимое |
|---|---|
| `shadow_text.png` | Текст на фоне с плавной тенью; гауссов шум со стандартным отклонением 3 |
| `faint_text.png` | Текст на 22 уровня яркости темнее фона 220, без шума |
| `text_mask.png` | Эталон текста: чёрный текст, белый фон; порог покрытия шрифтом 0.5 |
| `sharp_reference.png` | Исходные резкие фигуры, линии и текст |
| `blurred_shapes.png` | Эталон после гауссова размытия радиусом 1.5 |
| `noisy_shapes.png` | Эталон с гауссовым шумом σ = 9 в каждом RGB-канале |

[Результаты сравнения](RESULTS.md). Чтобы пересоздать набор, из папки лабораторной выполни `python make_samples.py`, затем `python compare_samples.py`.
