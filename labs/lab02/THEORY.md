# Методы обработки

Вариант 13 находится на пересечении строки «Локальная пороговая обработка (2 метода)» и столбца «Высокочастотные фильтры». Поэтому реализованы обе части: Ниблэк и Саувола, фильтр Лапласа и нерезкое маскирование.

## Яркость и границы

Для пороговой обработки RGB переводится в 8-битную яркость:

```text
I = round(0.299 R + 0.587 G + 0.114 B)
```

Повышение резкости выполняется отдельно для R, G и B. Все промежуточные вычисления идут в `float64`. Значения обрезаются до 0–255 и округляются только после обработки. Иначе отрицательные значения при работе с `uint8` могли бы превратиться в большие положительные.

За границей изображения повторяется ближайший крайний пиксель (`mode="edge"`). Это позволяет сохранить размер результата. Прозрачность входного файла накладывается на белый фон, ориентация EXIF учитывается. Обрабатывается первый кадр файла.

## Локальные пороги

Один порог для всего изображения плохо отделяет текст при неравномерном освещении. Здесь порог вычисляется отдельно для каждого пикселя по квадратному окну вокруг него.

Пусть `m` — среднее, `s` — стандартное отклонение яркости в окне:

```text
m = сумма I / число пикселей окна
s = sqrt(max(среднее(I²) − m², 0))
```

Среднее для всех окон находится через интегральное изображение: прямоугольная сумма получается из четырёх значений накопленной суммы. Поэтому время расчёта пропорционально размеру изображения, а не площади каждого окна. Отрицательную погрешность дисперсии перед корнем заменяем нулём.

**Ниблэк:**

```text
T = m − k·s
```

По умолчанию `k = 0.2`. В записи `T = m + k·s` этому соответствует `k = −0.2`. Метод сохраняет слабые перепады яркости, но может принимать шум фона за текст.

**Саувола:**

```text
T = m · (1 + k·(s/R − 1))
```

По умолчанию `k = 0.2`, `R = 128` для 8-битной яркости. В малоконтрастной области `s` мало и порог заметно ниже среднего. Это подавляет шум светлого фона, но может потерять бледный текст.

Формулы также приведены в документации [Ниблэка](https://scikit-image.org/docs/0.26.x/api/skimage.filters.html#skimage.filters.threshold_niblack) и [Сауволы](https://scikit-image.org/docs/0.26.x/api/skimage.filters.html#skimage.filters.threshold_sauvola). В приложении они реализованы самостоятельно.

Бинарное изображение строится так: `I < T` — чёрный текст, `I >= T` — белый фон. Равенство отнесено к фону; полностью однородная область без локального контраста становится белой даже при нулевой исходной яркости.

Окно должно быть нечётным (3–151). Маленькое окно может потерять внутреннюю часть толстого штриха; большое хуже подстраивается под изменение освещения. При увеличении k оба порога обычно снижаются и чёрных пикселей становится меньше.

## Фильтр Лапласа

Высокочастотная составляющая вычисляется ядром:

```text
 0  −1   0
−1   4  −1
 0  −1   0
```

То есть `H = 4I − верхний − нижний − левый − правый`. Повышение резкости: `J = I + aH`. В коде используется эквивалентная запись `J = I − aΔI`, где `ΔI` — дискретный лапласиан с центром −4.

Сумма коэффициентов высокочастотного ядра равна нулю: однородный участок не меняется. На границе контраст усиливается. Коэффициент `a` по умолчанию равен 0.6. Большие значения дают заметные ореолы и усиливают шум.

## Нерезкое маскирование

```text
B = Gσ * I
H = I − B
J = I + aH
```

`Gσ` — нормированное гауссово ядро: `g(x) = exp(−x²/(2σ²)) / сумма`. Радиус ядра равен `ceil(3σ)`. Двумерная свёртка разделена на вертикальную и горизонтальную — это быстрее, чем проход по всему двумерному окну.

Вычитаем сглаженное изображение, получаем детали и добавляем их к оригиналу. По умолчанию `a = 1.5`, `σ = 1.2`. Коэффициент задаёт усиление, σ — масштаб выделяемых деталей. При `a = 0` результат совпадает с оригиналом.

Описание метода: [Unsharp masking](https://scikit-image.org/docs/0.26.x/api/skimage.filters.html#skimage.filters.unsharp_mask).

## Почему выбраны эти изображения

| Пример | Что проверяем |
|---|---|
| Текст с тенью и шумом | Локальный порог при изменяющемся освещении; Саувола лучше подавляет шум фона |
| Бледный текст | Слабые штрихи на ровном фоне; Ниблэк лучше сохраняет текст |
| Размытые фигуры | Усиление границ после размытия |
| Зашумлённые фигуры | Ограничение методов: шум тоже содержит высокие частоты |

Примеры синтетические, поэтому известны маска текста и исходное резкое изображение. Для текста сравнивается IoU чёрных пикселей с маской, для резкости — MSE с эталоном. MSE не является универсальной мерой воспринимаемой резкости. Результаты и параметры находятся в [samples/RESULTS.md](samples/RESULTS.md).

Повышение резкости не восстанавливает всю информацию, потерянную при размытии. На шумном изображении ошибка относительно эталона растёт. Параметры нужно подбирать под конкретный материал.

## Как устроен код

`processing.py` выполняет расчёты над массивами, не обращаясь к интерфейсу. В `app.py` расчёт запускается в отдельном потоке. Основной поток обновляет Tkinter и принимает только последний запрошенный результат. При изменении параметров предыдущие результаты сбрасываются, чтобы случайно не сохранить устаревшую обработку.

Размер исходника сохраняется на всех этапах. Уменьшается только копия для показа в окне. `make_samples.py` создаёт тестовые изображения; готовое размытие Pillow используется только для подготовки размытого примера, а не в реализации алгоритмов приложения.
