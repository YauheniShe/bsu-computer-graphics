# Лабораторные работы

Каждая лабораторная работа размещается в отдельной папке: `lab01/`, `lab02/` и т. д.

В папку работы добавляются исходный код, необходимые входные данные и `README.md` с описанием задания и командами запуска. Для работ на Python зависимости указываются в `requirements.txt`, если используются сторонние библиотеки.
